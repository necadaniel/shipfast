# Changelog

All notable changes to this project are documented here.

## v0.2.0 — 2026-08-24 · build 1

### Added

- Version system — npm run release bumps semver, increments build numbers, writes CHANGELOG.md, and syncs package.json + lockfile
- Version displayed in the footer, dashboard header, and at /api/version
- Landing page composed from real sections; /api/lead route so ButtonLead works
- CI workflow, Prettier, .env.example, CLAUDE.md and AGENTS.md
- Social preview card generated from config.ts via next/og

### Changed

- Upgraded to Next 16.3.2, React 19.2.8, Stripe 22, Tailwind 4.3.3, TypeScript 6
- Build runs on Turbopack; the --webpack pin is no longer needed
- A user's plan is now derived from priceId instead of a duplicated column
- libs/api.ts uses fetch; axios and 11 other unused dependencies removed

### Fixed

- Dark mode — dark: utilities follow the theme toggle instead of the OS setting
- corner-squircle classes were a no-op; the Tailwind plugin was never registered
- Stripe webhook crashed on expanded customer objects and null users

### Removed

- ShipFast and env-sync branding, 10 unused components, and 8 one-off migration scripts
